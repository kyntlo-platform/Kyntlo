Accessibility

Kyntlo is committed to making the website easier to access, navigate, read, and use for as many visitors as possible.

Our Commitment

Kyntlo aims to provide a clear, readable, and usable website experience across modern browsers and devices. We consider accessibility when creating page structure, navigation, contrast, text clarity, keyboard focus, and responsive layouts.

Accessibility Practices

  • Use semantic headings and readable page structure where possible.
  • Maintain visible focus states for keyboard navigation in shared navigation and footer links.
  • Write descriptive link labels and page titles.
  • Use responsive layouts that work across desktop and mobile screen sizes.
  • Avoid relying only on color to communicate important information where practical.

Known Limitations

Some embedded third-party widgets, external social platforms, calendar tools, maps, or media may be controlled by third parties and may not fully follow the same accessibility behavior as the Kyntlo website.

Feedback

If you experience an accessibility issue on the Kyntlo website, contact us at Support@Kyntlo.ai. Please include the page URL, device, browser, assistive technology if applicable, and a short description of the issue.
